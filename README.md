# 💳 Loan & Credit Card Payment Simulator

## Description
A Streamlit application that simulates loan and credit card repayment outcomes based on different payment behaviours.

## Features

- Loan / credit card repayment simulation
- Financial product selection:
  - 🏠 House Loan
  - 🚗 Car Loan
  - 💳 Credit Card
- Payment behaviour comparison:
  - Early payment
  - On-time payment
  - Late payment
- Remaining balance visualization
- Interest cost comparison
- Payment schedule CSV download

## Technologies Used

- Python
- Streamlit
- Pandas
- Plotly
